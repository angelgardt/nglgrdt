# nglgrdt — CV-сайт Антона Ангельгардта

Статический сайт на Astro, публикуется на https://angelgardt.github.io/nglgrdt/.
ТЗ и текущая итерация — docs/spec.md. Журнал решений — docs/decisions.md.

## Команды

- npm run dev — локальный сервер
- npm run check — проверка типов и данных
- npm test — unit-тесты
- npm run build — сборка

## Где что лежит

- src/data/*.yaml — весь контент сайта
- src/content.config.ts — подключение коллекций; сами схемы — в src/lib/schemas.ts
- src/data/schemas/ — JSON Schema для редактора, создаются автоматически
- scripts/ — команды npm run i18n:report и npm run schemas
- src/lib/ — правила отображения (чистые функции + тесты рядом)
- src/i18n/ — языки и подписи интерфейса. Язык данных — русский (поле ru обязательно), язык сайта по умолчанию — английский (/), русская версия — /ru/. Не путать
- src/styles/tokens.css — все цвета, шрифты, отступы
- src/components/, src/layouts/, src/pages/ — интерфейс
- docs/ — документация для владельца
- migration/ — источники и отчёт миграции, в сборку не входит

## Правила

- Общение, отчёты, документация и комментарии в коде — на русском. Идентификаторы и сообщения коммитов — на английском.
- Контент берётся только из src/data. Никогда не выдумывай и не исправляй данные молча — предлагай правки.
- Цвета и размеры — только через токены. Внутренние ссылки — только через функцию, которая учитывает base.
- Изменил схему данных — обнови docs/content.md и JSON Schema для редактора.
- Изменил правило в src/lib — сначала тест, потом код.
- Новая зависимость или архитектурное решение — запись в docs/decisions.md.
- Перед коммитом: npm run check && npm test && npm run build.
- Работа идёт в ветках, в master — только через pull request.
- Репозиторий angelgardt/angelgardt.github.io можно только читать.
- Неоднозначно — спроси. Не блокирует — сделай простой обратимый вариант и напиши об этом в отчёте.
- В конце работы — короткий отчёт: что сделано, как проверить, что решено самостоятельно.
