# Данные сайта

Весь контент лежит в `src/data/*.yaml`. Код его только показывает. Это краткий справочник по полям; полное руководство с примерами появится в итерации 4.

## Как это устроено

- Один файл — один вид записей. Запись начинается с `- id: ...`.
- В VS Code с расширением YAML (Red Hat) работают автодополнение полей и подсветка ошибок. Их даёт первая строка файла: `# yaml-language-server: $schema=./schemas/...`. Не удаляйте её.
- Файлы в `src/data/schemas/` создаются автоматически при `npm run dev`, `npm run check` и `npm run build`. Руками их не правят. После добавления нового тега запустите любую из этих команд (или `npm run schemas`), и редактор начнёт его подсказывать.
- Ошибка в данных останавливает сборку. Сообщение называет файл, id записи и поле:

  ```
  src/data/courses.yaml → ranepa-modern-data-analysis → position: Позиция «msu-teacher» не найдена.
  ```

- Те же ошибки показывают `npm run check` и `npm test`.

## Общие правила

**Текст на двух языках** — объект `{ ru: "...", en: "..." }`. Поле `ru` обязательно, `en` — перевод.

**Даты** — строки в кавычках: `"2021"`, `"2021-10"` или `"2021-10-27"`. В поле `end` можно написать `present` — «по настоящее время». `end` не может быть раньше `start`. Если забыть кавычки, дата всё равно прочитается, но лучше их ставить.

**Служебные поля** есть у каждой записи:

| Поле     | Что значит                                                                        | По умолчанию |
| -------- | --------------------------------------------------------------------------------- | ------------ |
| `id`     | имя записи: строчные латинские буквы, цифры и дефисы; не повторяется внутри файла | —            |
| `tags`   | список id из `tags.yaml`                                                          | `[]`         |
| `pinned` | всегда показывать, не сворачивать                                                 | `false`      |
| `hidden` | не показывать нигде                                                               | `false`      |
| `notes`  | заметка для себя, на сайт не выводится                                            | —            |

Поле с неизвестным названием — ошибка: так ловятся опечатки вроде `organisation`.

## Файлы и поля

Поля, помеченные _текст_, — текст на двух языках. Обязательные выделены полужирным.

| Файл                   | Поля, кроме служебных                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `profile.yaml`         | один объект: **`name`**, **`positioning`**, **`location`** (_текст_, `en` обязателен), **`authorName`**, **`photo`**, **`focusAreas[]`**: **`id`**, **`title`**, **`text`** (_текст_, `en` обязателен), **`tag`**                                                                                                                                                                            |
| `contacts.yaml`        | **`kind`** (email, telegram, linkedin, github, whatsapp, skype, twitter, facebook, instagram, phone, other), **`url`**, `label`, `visible`, `primary`                                                                                                                                                                                                                                        |
| `tags.yaml`            | **`id`**, **`label`** (_текст_), `notes`                                                                                                                                                                                                                                                                                                                                                     |
| `positions.yaml`       | **`kind`** (teaching, research, academic, management, other), **`role`**, **`organization`**, `unit`, `context`, `description` (_текст_), `start`, `end`, `featured`                                                                                                                                                                                                                         |
| `courses.yaml`         | **`position`** (id из `positions.yaml`), **`title`** (_текст_), **`runs[]`**: **`start`**, `end`, `role`, `duties` (_текст_); `materialsUrl`                                                                                                                                                                                                                                                 |
| `education.yaml`       | **`level`** (bachelor, master, specialist, other), **`start`**, `end`, **`university`**, `faculty`, `department`, `program`, `track`, `specialty`, `qualification`, `gpa` (_текст_), `minor`: `institute`, `program`, `specialty`; `thesis`: **`title`**, `supervisor`, `advisor`, `reviewer` (у каждого **`name`** и `title`), `grades`: `supervisor`, `reviewer`, `commission`; `featured` |
| `extra-education.yaml` | **`kind`** (qualification, school, mooc), **`title`**, `track`, `organizer`, `organization`, `platform` (_текст_), **`start`**, `end`                                                                                                                                                                                                                                                        |
| `achievements.yaml`    | **`title`**, `context`, `organization` (_текст_), **`start`**, `end`                                                                                                                                                                                                                                                                                                                         |
| `languages.yaml`       | **`name`**, `level` (_текст_)                                                                                                                                                                                                                                                                                                                                                                |
| `skills.yaml`          | поле `groups` со списком групп: **`id`**, **`title`**, `items[]` (_текст_), `subgroups[]` (те же поля)                                                                                                                                                                                                                                                                                       |
| `interests.yaml`       | поле `groups` со списком групп: **`id`**, **`title`**, `items[]` (_текст_)                                                                                                                                                                                                                                                                                                                   |
| `projects.yaml`        | **`title`**, `role`, `description` (_текст_), `methods[]` (_текст_), `start`, `end`, `url`, `featured`                                                                                                                                                                                                                                                                                       |

| `conferences.yaml`     | **`event`**, **`talkTitle`**, `location` (_текст_), **`talkType`** (talk, poster, workshop), **`start`**, `end`                                                                                                                                                                                                                                                                              |
| `publications.yaml`    | **`authors[]`**, **`title`**, **`venue`**, **`year`**, `volume`, `issue`, `pages`, `status` (published, in-press, submitted), `doi`, `url`                                                                                                                                                                                                                                                   |
| `materials.yaml`       | **`kind`** (course, workshop, book, other), **`title`**, `audience`, `description`, `context` (_текст_), `year`, `url`, `copyright`                                                                                                                                                                                                                                                          |

Особенности:

- **Контакты.** `visible` по умолчанию `false`: контакт появится на сайте, только если написать `visible: true`. Ровно у одного контакта должно стоять `primary: true`, и он должен быть видимым — на него ведёт кнопка «Написать». Репозиторий публичный: всё, что записано в файл, видно на GitHub даже с `visible: false`.
- **Позиции.** `context` — мероприятие, курс или проект, в рамках которого была роль. Этого поля нет в ТЗ, оно добавлено при миграции. Если `start` и `end` не заданы, даты позиции будут браться из её курсов (правило появится в итерации 3).
- **Курсы.** Каждый раз, когда курс читался, — отдельная строка в `runs`.
- **Публикации.** Поля одноязычные: название и издание пишутся на языке публикации.
- **Профиль.** Пока перевода нет, в обязательных полях `en` стоит строка `TODO`.

## Перевод

```bash
npm run i18n:report
```

Команда выводит поля с `TODO`, затем поля без `en` по файлам и записям, и в конце — процент переведённых полей среди видимых записей.

## Если сборка упала из-за данных

1. Прочитайте сообщение: в нём файл, id записи и поле.
2. «Ошибка разметки YAML» — обычно это отступ, незакрытая кавычка или скобка. В сообщении указана строка.
3. «Тег … не найден» — добавьте тег в `tags.yaml` или исправьте опечатку.
4. «Нераспознанный ключ» — опечатка в названии поля.
5. Запустите `npm run check` ещё раз.
