# migration

Источники и отчёт миграции старого CV. В сборку сайта эта папка не входит.

| Что                          | Зачем                                                    |
| ---------------------------- | -------------------------------------------------------- |
| `REPORT.md`                  | отчёт для владельца: что перенесено, что нужно проверить |
| `migrate.py`                 | скрипт разовой миграции (Python 3, без зависимостей)     |
| `report-head.md`             | написанная вручную часть отчёта                          |
| `sources/old-site/`          | копии страниц старого сайта (коммит `a6baa59`)           |
| `sources/ru/`, `sources/en/` | `education.json` из прототипа на Vue                     |

## Повторный запуск

Миграция уже выполнена. После неё файлы `src/data/*.yaml` правятся руками, поэтому скрипт отказывается работать, если они существуют. Запуск с `--force` перезапишет все файлы данных и сотрёт ручные правки:

```bash
python3 migration/migrate.py --force
```

После запуска нужно отформатировать данные (`npm run format`) и собрать отчёт заново: `REPORT.md` — это `report-head.md` плюс `generated.md`, который пишет скрипт.
